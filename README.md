# fashion-lookbook
# 🖤 Fashion Lookbook Website

A sleek and elegant single-page fashion lookbook site showcasing seasonal collections from top global brands like **Zara**, **H&M**, **Nike**, **Dior**, **Gucci**, and **Puma**.

## 🌐 Live Preview
You can deploy this page easily using [GitHub Pages](https://pages.github.com/) or [Netlify](https://www.netlify.com/).

## 📁 Project Structure

```
fashion-lookbook/
├── nav_bar.html
└── (Recommended assets folder for images, CSS, JS)
```

> **Note:** Image paths currently reference local directories. You should move image assets into a folder like `/assets/images/` in the project directory and update the `src` attributes in the HTML accordingly.

## 🚀 Features

- 🔍 **Search Bar** – Filter collections by brand or season in real time using jQuery.
- 🎛️ **Season Filter Tabs** – Toggle between Spring/Summer and Fall/Winter collections.
- 🖼️ **Brand Cards** – Stylish brand previews with hover animations.
- 📩 **Newsletter Subscription UI** – Front-end section for user subscription (non-functional).
- 📱 **Responsive Layout** – Built with Bootstrap 5 and Tailwind CSS for modern responsiveness.

## 🛠️ Built With

- HTML5
- [Bootstrap 5](https://getbootstrap.com/)
- [Tailwind CSS](https://tailwindcss.com/)
- [jQuery](https://jquery.com/)

## 🔧 Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/fashion-lookbook.git
   cd fashion-lookbook
   ```

2. Open `nav_bar.html` in your browser to view the page locally.

3. To fix image loading:
   - Place all image files inside an `assets/images/` folder.
   - Replace image paths like  
     `/home/rguktrkvalley/Pictures/image.jpg`  
     with  
     `assets/images/image.jpg` in `nav_bar.html`.
